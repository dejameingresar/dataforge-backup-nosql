DataForge Backup

Estrategias de respaldo para bases de datos NoSQL · proyecto SI-783

Qué es esto

DataForge Backup compara seis estrategias de respaldo sobre tres motores de bases de datos NoSQL: MongoDB, Redis y Neo4j. Para cada una mide el tamaño del archivo generado, cuánto tarda y su hash SHA-256; después destruye los datos, restaura el respaldo y cuenta lo que volvió.

Ese último paso es el que importa: varias herramientas terminan con código de salida cero sin haber restaurado nada. Aquí el resultado se verifica contando, no confiando en el código.

Las seis restauraron correctamente. Las cifras medidas de cada corrida están en indice/indice_respaldos.json, con el tamaño, el tiempo y el hash de cada artefacto.

Los tres motores viven en la máquina del laboratorio, no en este servicio web: un sitio público no puede alojar una base de datos. Por eso el panel 1 los muestra como no disponibles, y los botones de respaldar necesitan ejecutarse en el laboratorio.
